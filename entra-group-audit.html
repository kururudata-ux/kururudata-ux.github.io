Entra ID グループ監査

グループの全体像、入れ子構造、循環依存、空グループ、少人数グループ、未使用ユーザー候補を収集し、判断しやすいHTMLレポートへまとめるPowerShellスクリプトです。

PowerShell 7+ Microsoft Graph HTML / CSV / Mermaid 読み取り専用

このスクリプトの目的

Microsoft Entra IDに登録されたグループを横断的に点検し、管理上のリスクや棚卸し対象を早期に特定することを目的とします。

  • 全グループと直接メンバー数を一覧化する
  • 親グループと子グループの依存関係を抽出する
  • グループ同士が相互参照する循環依存を検出する
  • メンバーが空、または直接メンバーが1～5名のグループを抽出する
  • 無効アカウント、長期間サインインがないユーザー、サインイン履歴がないユーザーを候補として抽出する
  • HTML、CSV、JSON、Mermaid形式で監査結果を保存する
このスクリプトは読み取り専用です。グループ、ユーザー、メンバーシップを変更しません。

実行する上での前提環境

項目要件
PowerShellPowerShell 7.0以降
モジュールMicrosoft.Graph.Authentication を含むMicrosoft Graph PowerShell SDK
ネットワークgraph.microsoft.com およびMicrosoftサインインエンドポイントへ接続できること
実行ユーザー対象テナントへサインインでき、必要な委任アクセス許可へ同意済みであること
必要権限Group.Read.All、GroupMember.Read.All、User.Read.All、Directory.Read.All、AuditLog.Read.All
保存先レポート出力先へ書き込みできること

モジュールの準備

Install-Module Microsoft.Graph -Scope CurrentUser
サインイン活動を取得するには AuditLog.Read.All が必要です。取得しない場合は -SkipSignInActivity を指定します。

実行する手順

  1. EntraGroupAuditReport.ps1 を任意の作業フォルダーへ配置します。
  2. PowerShell 7を起動します。
  3. 対象テナントIDまたはテナントドメインと、サインインに使用するアカウントを指定して実行します。
  4. Microsoftのサインイン画面で対象アカウントを選択し、必要な権限へ同意します。
  5. 処理完了後、生成されたフォルダーの Report.html をブラウザーで開きます。

通常実行

.\EntraGroupAuditReport.ps1 `
  -TenantId "<Tenant ID または tenant.onmicrosoft.com>" `
  -RequiredSignedInAccount "<監査用アカウント>" `
  -InactiveDays 90

サインイン活動を確認しない場合

.\EntraGroupAuditReport.ps1 `
  -TenantId "<Tenant ID または tenant.onmicrosoft.com>" `
  -RequiredSignedInAccount "<監査用アカウント>" `
  -SkipSignInActivity

サンプルデータで画面を確認する場合

.\EntraGroupAuditReport.ps1 `
  -GenerateSampleData `
  -SampleGroupCount 10000

出力されたレポートの見方

HTMLレポートの左側インデックスから各セクションへ移動できます。右上ではなく左ペイン上部のボタンで、日本語と英語を切り替えます。

赤: 緊急対応 循環依存、無効アカウント、ユーザーオブジェクト未検出など。権限設計とメンバーシップを優先して確認します。
黄: 要対応 長期未使用、サインイン履歴なしなど。利用実態と業務上の必要性を所有者へ確認します。
緑: 要確認 空グループや少人数グループ。利用目的、所有者、アプリやロールへの割り当てを確認してから廃止を判断します。

確認の推奨順序

  1. 優先対応で全体の検出件数を把握します。
  2. 循環依存で相互参照しているグループを特定します。
  3. 未使用ユーザー候補で無効アカウントと長期未使用アカウントを確認します。
  4. 空グループ・5名以下グループで棚卸し候補を確認します。
  5. Mermaid図で依存関係の全体像を確認し、必要に応じてCSVで詳細分析します。
抽出結果は削除対象を確定するものではありません。グループ所有者、アプリ割り当て、ライセンス付与、アクセスパッケージ、動的メンバーシップなどへの影響を確認してから変更してください。
