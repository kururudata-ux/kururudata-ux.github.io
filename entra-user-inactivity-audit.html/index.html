Entra ID ユーザー監査（非アクティブ）

EntraUserInactivityReport.ps1 は、サインイン履歴がないユーザーや長期間サインインがないユーザーを抽出し、ユーザータイプ別に可視化したレポートを生成します。

PowerShell 5.1+Microsoft GraphUser Inactivity
ダウンロードページへ

このスクリプトでできること

  • 全ユーザーを取得し、最終サインイン時刻を評価
  • しきい値日数（既定90日）で非アクティブ判定
  • ユーザータイプ別の未使用率を集計
  • HTML / CSV / JSON / Markdown 形式で出力

前提環境

項目要件
PowerShellWindows PowerShell 5.1 以上
モジュールMicrosoft.Graph.Authentication（Microsoft Graph PowerShell SDK）
必要権限User.Read.All / Directory.Read.All / AuditLog.Read.All
出力先レポート出力フォルダーに書き込み可能

実行例

.\EntraUserInactivityReport.ps1
  -TenantId "<Tenant ID>"
  -RequiredSignedInAccount "<監査アカウントUPN>"
  -InactiveDays 90
.\EntraUserInactivityReport.ps1 -GenerateSampleData -SampleUserCount 10000
詳細ファイルとスクリプト本体は、ダウンロードページから取得できます。
