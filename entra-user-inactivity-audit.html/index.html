P-05 / MICROSOFT ENTRA ID

Entra ID ユーザー監査（非アクティブ）

サインイン履歴がないユーザー、長期間サインインしていないユーザーを抽出し、ユーザータイプ別に未使用率を可視化するPowerShellスクリプトです。

PowerShell 5.1+ Microsoft Graph HTML / CSV / JSON 読み取り専用
ダウンロードページ

このスクリプトの目的

Microsoft Entra IDのユーザー利用実態を定点確認し、未使用アカウント候補の棚卸しを効率化することを目的とします。

  • 最終サインイン日時をもとに非アクティブユーザーを判定する
  • サインイン履歴なしのユーザーを抽出する
  • UserType（Member/Guest等）単位で未使用率を集計する
  • 監査結果をHTML・CSV・JSON・Markdown形式で保存する
このスクリプトは読み取り専用です。ユーザー属性やアカウント状態を変更しません。

実行する上での前提環境

項目要件
PowerShellWindows PowerShell 5.1以降
モジュールMicrosoft.Graph.Authentication を含むMicrosoft Graph PowerShell SDK
ネットワークgraph.microsoft.com へ接続可能であること
必要権限User.Read.All、Directory.Read.All、AuditLog.Read.All
保存先レポート出力先フォルダーへ書き込み可能であること

実行する手順

  1. EntraUserInactivityReport.ps1 を作業フォルダーへ配置します。
  2. PowerShellを起動し、対象テナント情報を指定して実行します。
  3. Microsoftサインイン画面で監査用アカウントを選択します。
  4. 処理完了後、生成された Report.html を開きます。

通常実行

.\EntraUserInactivityReport.ps1
  -TenantId "<Tenant ID>"
  -RequiredSignedInAccount "<監査用アカウント>"
  -InactiveDays 90

サンプルデータで検証

.\EntraUserInactivityReport.ps1
  -GenerateSampleData
  -SampleUserCount 10000

実行後に出力される内容

ファイル内容
Report.html非アクティブ監査の可視化レポート
Summary.json監査概要（件数、しきい値、日時）
Users.csv全ユーザー一覧
InactiveUsers.csv非アクティブと判定されたユーザー一覧
UserTypeSummary.csvUserType別の件数・未使用率集計
Report.mdテキストベースの監査サマリー

出力されたレポートの見方

まずサマリーで全体件数を確認し、その後にユーザータイプ別の未使用率と詳細一覧を確認します。

赤: 緊急確認 無効アカウントや想定外の高権限ユーザーが未使用として抽出された場合。
黄: 要対応 しきい値日数を超えてサインインがないユーザー。
緑: 定期レビュー サインイン履歴がないユーザーやGuestアカウントの棚卸し。
抽出結果は削除対象確定ではありません。所有者・業務利用状況・権限影響を確認した上で判断してください。
